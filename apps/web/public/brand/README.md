# ORLEN brand assets (client-supplied)

Place the **official ORLEN company logo** files here (do not use unofficial downloads):

| File | Usage |
|---|---|
| `orlen-logo.svg` | Sidebar expanded, login (light backgrounds) |
| `orlen-logo-dark.svg` | Optional — dark sidebar / login showcase |
| `orlen-logo-mark.svg` | Optional — collapsed sidebar mark (square) |

Recommended: SVG with transparent background, minimum clear space per client brand guidelines.

Until these files exist, the app shows a **text fallback** (`ORLEN` word + ITDMS product name) — not a recreated logo.
